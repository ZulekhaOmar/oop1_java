## Project overview 
This project demonstrates the differences between Concrete Classes, Abstract Classes, and Interfaces in Java using a vehicle system example.
## Class Types 
## 1.  Interface 
 A contract that specifies methods that implementing classes must provide
     Characteristics:
           - Can contain abstract and default methods
           - Multiple interfaces can be implemented by a class
           - Used to define a common behavior across unrelated classes
## 2. Abstract 
 A class that cannot be instantiated and may contain abstract and concrete methods
       Characteristics:
             - Can have constructor, fields, and methods
             - Can provide default implementations
             - Used to define a base class with common functionality for subclasses
## 3. Concrete Class
 A fully implemented class that can be instantiated
       Characteristics:
             - Provides complete implementations for all inherited abstract methods
             - Can be used to create objects
             - Can extend one class and implement multiple interfaces
